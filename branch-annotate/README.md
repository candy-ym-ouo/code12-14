# 跨年份同株枝条照片标注（branch-annotate）

从零实现的照片标注子系统，零第三方依赖（仅 Python 3 标准库 + 原生 JS）。
解决三个问题：

1. **跨年份同株枝条共用底图** —— 同株只保留一张 base 底图；每年照片、
   每张局部裁剪图都通过一个坐标变换（仿射 / 单应 Homography）挂到父图；
   **所有标注只存底图归一化坐标**，在任意年份、任意裁剪图上自动落到枝条
   同一位置。
2. **标注坐标随裁剪/缩放还原** —— 裁剪图记录相对父图的 `cropRect` 与
   3×3 `frame`；视图缩放/平移只改 Viewport 参数，永不改动标注本身；
   底图坐标经「底图→照片」「像素→屏幕」两级映射双向可逆。
3. **多人同时编辑同一标注按版本合并** —— 每个标注叶子字段带版本向量；
   提交时做 base / current / proposed **三向合并**：不同字段自动合并、
   相同改动收敛、同字段冲突先提交者胜出并进入冲突面板人工裁决。

## 运行

```bash
cd branch-annotate
python3 server.py --port 8000
# 浏览器打开 http://127.0.0.1:8000/
```

打开后点左上角「载入演示数据」，会在本地生成：

- `2023 底图`（1200×800 手绘枝条）；
- `2024-04`（单应配准 + 轻微透视 + 新长叶片）；
- `2025-04`（仿射配准）；
- `2024-04 顶芽特写`（对 2024 图再裁剪，形成 **底图→配准→裁剪** 两跳坐标链）；
- 3 个底图坐标标注：顶芽(点)、老叶痕(多边形)、观测区域(矩形)。

切换年份/特写 Tab，缩放平移，标注始终“焊”在枝条同一结构上。

右侧「并发演示」：

- **并发改不同字段**：bob 改 label、alice 同时改 color → 自动合并，无冲突；
- **并发改同一字段**：两人基于同一版本把 label 改成不同值 → 后提交者收到
  409 与冲突详情，先提交者胜出，右侧面板可一键改用任一方的值（仲裁）。
- 也可以开两个浏览器标签页，右上角分别选 alice / bob，实时编辑
  （长轮询事件推送，另一标签页会即时刷新）。

```bash
cd branch-annotate

```

35 项：仿射/单应估计（精确解 + 最小二乘）、裁剪坐标链往返、Viewport
锚点缩放还原、版本向量三向合并（字段自动合并 / 同值收敛 / 同字段冲突 /
删除 / 仲裁）、以及真实 HTTP 端到端（建株→配准→裁剪→并发提交 409→
长轮询唤醒→静态页面）。

## 坐标设计

```
屏幕 CSS 像素
   │  Viewport: s = scale·p + t        （缩放/平移只改这里）
   ▼
当前照片像素 ──(/w,/h)──▶ 当前照片归一化 [0,1]²
   │  frame 链：沿 parent 逐张 3×3 复合（裁剪是仿射，配准可单应）
   ▼
base 底图归一化 [0,1]²   ◀── 标注只存在这里，分辨率无关、年份无关、裁剪无关
```

- `frame` 方向固定为 **父图归一化 → 本图归一化**，裁剪图的 frame 为
  `x'=(x-x₀)/w, y'=(y-y₀)/h`。
- 配准：在父图/本图点 ≥3 对控制点，3 对解仿射，≥4 对走 Hartley
  归一化 DLT 解单应（手写 Jacobi 特征分解取最小奇异向量，无 numpy）。

## 合并语义

标注文档摊平为叶子路径（如 `geometry.points.2.0`），每叶子带
`vv = {clientId: counter}`。提交体：

```json
{ "clientId": "alice", "revision": 7,
  "base": {...我编辑前看到的标注...},
  "proposed": {...我改成的标注...},
  "baseVV": {"alice": 6} }
```

| 情况 | 结果 |
| --- | --- |
| 只有我改 | 直接采纳 |
| 对方改了别的叶子，我改这个叶子 | 自动合并（拖不同顶点也是不同叶子） |
| 双方改成相同值 | 收敛，无冲突 |
| 双方改同一叶子且值不同 | 先提交者落库，后提交者 409 + 冲突项 |
| 删除 | 视为写 `deleted=true`，与改 label 可自动合并 |
| 人工仲裁 | POST resolve，选定值写入新版本 |

冲突不会被静默吞掉，也不会因字段粒度太粗（整文档一把锁）而误伤无关编辑。

## 目录

```text
branch-annotate/
├─ server.py          # http.server 路由：分支/照片/标注/配准/裁剪/长轮询
├─ geometry.py        # 3x3 变换、仿射/单应估计、裁剪、坐标链、Viewport
├─ merge.py           # 摊平/还原、版本向量、三向合并、冲突仲裁
├─ store.py           # 线程安全内存仓库（生产可换数据库，接口很小）
├─ static/
│  ├─ index.html
│  ├─ style.css
│  ├─ geometry.js     # geometry.py 的浏览器镜像（同构）
│  └─ app.js          # Canvas 绘制/命中/拖拽、裁剪、对齐对话框、演示数据
└─ tests/
   ├─ test_geometry.py
   ├─ test_merge.py
   └─ test_e2e.py
```
